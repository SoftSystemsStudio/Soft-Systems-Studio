## Phase 1: Pre-Kickoff (Before First Call)

### Administrative

- [ ] Service Agreement signed
- [ ] Deposit invoice sent
- [ ] Deposit received
- [ ] Client folder created in `02-clients/[client-name]/`
- [ ] Project added to project management tool
- [ ] Kickoff meeting scheduled

### Client Setup

- [ ] Client contact info documented
- [ ] Decision maker(s) identified
- [ ] Communication preferences noted (email, Slack, phone)
- [ ] Timezone recorded

---

## Phase 2: Kickoff Meeting

### Agenda Items

- [ ] Introductions and roles
- [ ] Review scope and timeline
- [ ] Discuss communication cadence
- [ ] Identify immediate needs/blockers
- [ ] Schedule recurring check-ins
- [ ] Q&A

### Collect During Kickoff

- [ ] Brand guidelines / logo files
- [ ] Current website URL (if applicable)
- [ ] Competitor examples they like
- [ ] Content outline or sitemap preferences
- [ ] Key stakeholders to involve

### Deliverables from Kickoff

- [ ] Send kickoff summary email within 24 hours
- [ ] Share project timeline/Gantt
- [ ] Send access request list

---

## Phase 3: Access & Integrations

### Domain & Hosting

- [ ] Domain registrar access (or transfer ownership)
- [ ] DNS control confirmed
- [ ] Existing hosting access (if migrating)

### Third-Party Services

**For Website Projects:**

- [ ] Google Analytics access
- [ ] Google Search Console access
- [ ] Current CMS access (if migrating content)
- [ ] Social media accounts (for links)

**For Voice Receptionist:**

- [ ] Twilio account created (or invite sent)
- [ ] Phone number ported or new number selected
- [ ] Calendar access (Acuity, Calendly, Google Calendar)
- [ ] CRM access (if integrating)
- [ ] Business hours confirmed
- [ ] After-hours handling defined
- [ ] Escalation contacts documented

**For Chat Support:**

- [ ] Website admin access (to install widget)
- [ ] Knowledge base content provided
- [ ] FAQ list provided
- [ ] CRM integration credentials

**For Workflow Automation:**

- [ ] All tool credentials collected
- [ ] API keys generated
- [ ] Webhooks documented
- [ ] Test accounts created

## Phase 6: Launch Preparation

### Technical Checklist

- [ ] SSL certificate configured
- [ ] DNS propagation verified
- [ ] All redirects in place
- [ ] Analytics tracking verified
- [ ] Error monitoring enabled
- [ ] Backups configured
- [ ] Phone forwarding tested (voice)

### Client Preparation

- [ ] Launch date confirmed
- [ ] Team notified of go-live
- [ ] Training session scheduled
- [ ] Documentation shared
- [ ] Emergency contact established

---

## Phase 7: Launch Day

### Go-Live Tasks

- [ ] Deploy to production
- [ ] Verify everything works
- [ ] Test critical user flows
- [ ] Monitor for errors
- [ ] Confirm with client

### Immediately After Launch

- [ ] Send "We're Live!" email to client
- [ ] Share login credentials (secure method)
- [ ] Provide quick reference guide
- [ ] Schedule 1-week check-in

---

## Phase 8: Post-Launch

### Week 1

- [ ] Daily monitoring for issues
- [ ] Respond to any bugs within 24 hours
- [ ] Check-in call with client
- [ ] Gather initial feedback

### Week 2-4 (Warranty Period)

- [ ] Weekly check-ins
- [ ] Address any issues
- [ ] Optimize based on real usage
- [ ] Collect testimonial/case study content

### At 30 Days

- [ ] Final project review call
- [ ] Confirm satisfaction (guarantee)
- [ ] Discuss ongoing support options
- [ ] Request testimonial
- [ ] Send final invoice (if applicable)
- [ ] Archive project files
